# EdgeLink v0.3.0

EdgeLink v0.3 connects the software-tested protocol and Linux gateway to a physical
ESP32-WROOM-32 and SHT30 temperature/humidity sensor.

## Highlights

- Real SHT30 sampling over I2C on pins SDA 21 and SCL 22
- ESP32 Wi-Fi/TCP client using the EdgeLink binary wire format
- HELLO registration and continuous TELEMETRY delivery
- CRC-32 encoding and ACK type, sequence, and checksum validation
- Acknowledged five-second HEARTBEAT messages
- Automatic recovery after Gateway shutdown and restart
- Automatic recovery after a controlled Wi-Fi interruption
- Local, Git-ignored Wi-Fi and Gateway endpoint configuration
- Physical ESP32 telemetry validated against the Ubuntu Linux `epoll` gateway

## Validation

The physical device was tested with the following sequence:

1. Connect to Wi-Fi and establish a TCP session.
2. Send HELLO and validate its ACK.
3. Stream real SHT30 measurements and validate every telemetry ACK.
4. Send and acknowledge periodic heartbeats.
5. Stop and restart the Gateway without rebooting the ESP32.
6. Inject a one-time Wi-Fi disconnect and verify automatic session recovery.
7. Connect the same physical device to the Ubuntu ARM64 `epoll` gateway.

The repository also retains deterministic protocol tests, TCP fragmentation and
coalescing coverage, CRC rejection and resynchronization tests, an Ubuntu CI build,
and a concurrent simulated-device load generator.

## Scope

This release completes the physical device communication milestone. Persistent
storage, dashboards, and RS485/Modbus integration remain post-v0.3 work.
