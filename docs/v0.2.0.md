# EdgeLink v0.2.0

EdgeLink v0.2 replaces the Linux thread-per-connection path with a non-blocking `epoll`
event loop while preserving the v0.1 wire protocol.

## Highlights

- Non-blocking listener and client sockets
- Per-client TCP stream parsers and device identity tracking
- Queued ACK writes with temporary `EPOLLOUT` interest
- Read draining until `EAGAIN`
- Inactivity timeout and graceful signal-driven shutdown
- Concurrent load generator with delivery and throughput statistics
- Ubuntu CI and automated multi-device smoke testing

## Compatibility

The binary protocol is unchanged. Existing v0.1 simulators and future ESP32 clients can
connect to the v0.2 epoll gateway without changing their frame encoder.

## Validation commands
